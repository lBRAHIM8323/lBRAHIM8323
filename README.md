## 👨‍💻 About

I’m an aspiring Machine Learning / AI Engineer based in United Arab Emirates. I specialize in:

- Implementing AI and ML models into the backend of software systems using Python.  
- Fine‑tuning large language models (Llama, GPT, etc.) for custom tasks.  
- Staying up to date with the latest research and advancements in the AI world.

I’m passionate about turning data into actionable insights and building scalable, production‑ready AI solutions.

## 🔍 What I Do

- **Backend AI Integration:** Embed machine learning models into REST APIs and microservices.  
- **Model Development:** Train, evaluate, and deploy models for NLP, computer vision, and time series forecasting.  
- **Fine‑Tuning & Optimization:** Customize pre‑trained models for domain‑specific tasks, optimize inference speed, and reduce memory footprint.  
- **Continuous Learning:** Follow top conferences (NeurIPS, ICML, CVPR) and implement cutting‑edge papers and open‑source projects.
