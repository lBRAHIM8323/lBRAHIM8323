## About Me

I'm an AI/ML Engineer focused on designing, developing, and deploying production-oriented AI systems.

My work revolves around Generative AI, Large Language Models, Retrieval-Augmented Generation (RAG), AI agents, multimodal systems, and computer vision.

I enjoy working across the entire AI engineering lifecycle, from data processing and model fine-tuning to inference optimization, backend integration, and deployment.

- Building production-ready LLM applications and AI agents.
- Fine-tuning open-source language models using LoRA and quantization.
- Developing scalable RAG pipelines and intelligent retrieval systems.
- Working with multimodal AI and vision-language models.
- Optimizing model inference and GPU workloads.
- Building AI-powered automation and real-time voice applications.
